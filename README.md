# Site — Imobiliária

Site de uma imobiliária fictícia com layout moderno, banner de destaque, galeria de imagens em mosaico e formulário de contato.

## Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

## Seções da página

- Header com logo
- Banner com chamada e formulário de captação de leads
- Seção de chamada para o negócio
- Galeria mosaico com imagens de imóveis
- Rodapé

## Estrutura

```
Site-Imobiliaria/
├── index.html
├── css/
│   └── style.css
└── imagens/
```

## Como visualizar

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd Site-Imobiliaria
```

Abra o `index.html` no navegador. Nenhuma dependência necessária.
